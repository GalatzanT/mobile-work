# Car Management App

## Descriere

Această aplicație permite gestionarea unei colecții de mașini. Utilizatorii pot adăuga mașini și vizualiza lista lor în timp real folosind **WebSockets**. Frontend-ul este construit cu **Ionic + React**, iar backend-ul este realizat în **Node.js**.

---
